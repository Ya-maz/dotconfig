---
name: figma-to-component
description: Анализ изображения и создание React+TS+SCSS компонента
---

Открой изображение по указанному пути или ссылке и проанализируй его с помощью vision tool.

1. Твоя задача:
   1. Внимательно изучить интерфейс на изображении.   
   2. Определить следующие элементы макета:
      - структуру layout;
      - основные UI-блоки;
      - карточки;
      - кнопки;
      - поля ввода;
      - списки;
      - заголовки;
      - иконки;
      - отступы;
      - вложенность элементов.   
   3. Изучи компонент по пути $4 (референс).  
   4. Используй референсный компонент как образец:
      - структуры файлов;
      - организации React-компонента;
      - подходов к TypeScript;
      - подходов к SCSS;
      - имён классов;
      - соглашений проекта.   
   5. Не анализируй весь проект без необходимости — если достаточно референсного компонента, используй только его как образец (см.$4).   
   6. Результат: создай новый компонент на основе дизайна изображения и архитектуры референса при максимально точном воспроизведении макета.
      - Создавай подкомпоненты при необходимости для интерфейсов из нескольких частей;
      - Обнови все необходимые файлы в указанной директории $2 с именем компонента $3;   
   7. Сохрани код согласно аргументу — показывай итоговый список созданных и изменённых файлов.

2. Важно:
   1. Не выполнять глобальный поиск по всему проекту (см.$4, см.$2/$3);
   2. Ориентируйся на референсный компонент;   
   3. Придерживайся архитектуры и стиля референсного компонента $4;   
   4. Стремись к максимально точному воспроизведению макета с дизайном с изображения $1.

3. Аргументы:
   - см.$1 = путь/ссылка на изображение (например, /mnt/c/designs/user-card.png);  
   - см.$2 = директория для нового компонента;   
   - см.$3 = имя создаваемого файла или папки с подкомпонентами;  
   - см.$4 = референсный компонент как образец.
